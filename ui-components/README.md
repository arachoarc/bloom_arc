# UI 컴포넌트 보관함

UI 컴포넌트의 CSS 코드와 스크린샷을 모아 두는 폴더입니다.

```
ui-components/
├── css/           컴포넌트 CSS 코드 (.css)
└── screenshots/   컴포넌트 스크린샷 (.png, .jpg, .webp)
```

## 파일 이름 규칙

CSS 파일과 스크린샷은 **같은 이름**으로 저장하면 짝을 찾기 쉽습니다.

| 컴포넌트 | CSS | 스크린샷 |
| --- | --- | --- |
| 기본 버튼 | `css/button-primary.css` | `screenshots/button-primary.png` |
| 상품 카드 | `css/card-product.css` | `screenshots/card-product.png` |

- 영어 소문자와 하이픈(`-`)만 쓰기 (예: `navbar-mobile`)
- 띄어쓰기와 한글은 파일 이름에 쓰지 않기
