# 알림 신청 → 구글 스프레드시트 연결

1. 구글 스프레드시트를 새로 만든다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 기본 코드를 지운 뒤 `notify.gs` 내용을 붙여 넣고 저장한다.
3. 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
   - 속성: `SECRET`, 값: 아무도 모르는 긴 문자열 (예: `openssl rand -hex 24` 결과)
4. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 후 권한 승인, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사
5. 프로젝트의 `.env.local` (그리고 배포 환경, 예: Vercel 환경 변수)에 추가:

   ```
   NOTIFY_SHEET_URL=https://script.google.com/macros/s/.../exec
   NOTIFY_SHEET_SECRET=3번에서 넣은 값
   ```

6. 개발 서버를 다시 시작한다. 폼에서 신청하면 `notify` 시트에 `신청 시각 / 이메일 / 언어 / 알림 종류` 가 한 줄씩 쌓인다. 같은 이메일은 한 번만 저장된다.

`notify.gs` 를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영된다.
